The project’s included environment uses Python 3.12. Please allow python.exe to load approved Python native extensions (.pyd) and their required DLLs. Carbon Black App Control is currently blocking NumPy’s _multiarray_umath extension, which prevents NumPy and OpenCV from loading.
Components needed
- Python 3.12 runtime and virtual environment
- NumPy, including its native .pyd and DLL components
- OpenCV (cv2), including its native components
- PyTorch (torch), for model inference; CUDA support is optional, since the app can use CPU
- RF-DETR 1.11.0, for document detection
- pytesseract 0.3.13 or later and the Tesseract OCR executable
- PyMuPDF 1.28.2 or later
- Pillow 12.3.0 or later
- The required transitive dependencies of these packages
The project’s direct Python package requirements are listed in requirements.txt. The annotation tool also uses Python’s Tkinter GUI library.
Please allow the project to read its input PDFs, images, and model checkpoint, and to write results under its output and annotation folders. An approved development environment with these dependencies enabled would also work.
These components are needed for PDF and image processing, document detection, OCR, and Aadhaar/PAN masking.
